This is a repository for the study of _Mirafra passerina_: Seasonal song turnover and cultural conformity 
in a nomadic African songbird
The main analysis code is in main.Rmd with extra in sliding_window_cor.cpp and acoustic_clustering.R
The machine learning analysis can be found in embed_perch.py 
Precomputed dissimilarity matrices are in the output folder.
Metadata about the recordings is in the Data folder.
